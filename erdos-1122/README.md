# Erdős Problem 1122 (`erdos-1122`)

Standalone Lean 4 (`leanprover/lean4:v4.35.0-rc2`) formalization package for [Erdős Problem 1122](https://www.erdosproblems.com/1122) (Erdős 1946, Mangerel 2022) on coprime-additive arithmetic functions $f : \mathbb{N} \to \mathbb{R}$ ($f(ab) = f(a) + f(b)$ whenever $\gcd(a, b) = 1$) whose descent set $A = \{n \ge 1 : f(n + 1) < f(n)\}$ satisfies $|A \cap [1, X]| = o(X)$ as $X \to \infty$, and whether $f(n) = c \log n$ for all $n \ge 1$.

## Verified Results

The two upstream variants are `Erdos1122.erdos_1122.variants.monotone` and `Erdos1122.erdos_1122.variants.sub_tendsto_zero`. The remaining 28 theorems live in the `Erdos1122.Core` namespace as auxiliary results.

- **Coprime Cross-Step Identities, Finitely Supported `o(X)` Rigidity, and Erdős's 1946 Monotone Theorem (`Erdos1122Unified435.lean`):**
  - `erdos1122_conjecture_implies_empty_descent_prop` and `coprime_cross_step_diff_eq`: establish the implication from `Erdos1122Conjecture` to `Erdos1122EmptyDescentProp` and the coprime cross-step identity $f((a + 1)b) - f(a(b + 1)) = (f(a + 1) - f(a)) - (f(b + 1) - f(b))$ for $\gcd(a, b + 1) = \gcd(a + 1, b) = 1$.
  - `finitely_supported_erdos1122_unconditional`: proves `Erdos1122Conjecture` for coprime-additive functions that vanish on every positive integer coprime to a fixed `Q ≥ 1`, and shows such a function is identically zero on the positive integers.
  - `coprime_additive_mul_of_descentSet_empty`, `empty_descent_eq_scaled_log_unconditional`, and `erdos1122_empty_descent_prop_holds`: prove complete additivity $f(ab) = f(a) + f(b)$ under $A = \emptyset$ via the coprime sandwich and coprime doubling sequence, and prove Erdős's 1946 monotone logarithmic rigidity theorem $f(m) = \frac{f(2)}{\log 2} \log m$ unconditionally.
- **Erdős's 1946 `o(1)`-Difference Theorem and Wirsing Window-Averaged Coprime Sandwich Shifts (`WirsingWindowAveragingAndLittleODiffRigidity1122.lean`):**
  - `coprime_additive_mul_of_isLittleO_diff`, `littleO_diff_eq_scaled_log_unconditional`, and `erdos1122_littleO_diff_prop_holds`: prove complete additivity and unconditional logarithmic rigidity $f(m) = \frac{f(2)}{\log 2} \log m$ whenever $f(n + 1) - f(n) = o(1)$.
  - `wirsing_zero_density_eventually_exists_good_sandwich_shift`: for a coprime-additive `f` with descent count `o(X)` and fixed `a, b ≥ 1`, every sufficiently large `K` admits a shift `k ∈ [1, K]` whose sandwich gap satisfies $|f(ab) - f(a) - f(b)| \le f(w_+(a,b,k)) - f(w_-(a,b,k))$. It guarantees this gap inequality only; it does not claim either window is descent-free.
- **Controlled-Descent `K`-Window Telescoping, Logarithmic Ratio Squeezes, and Dyadic-Shell Equivalence (`ControlledDescentTelescopingAndBoundedJumpRigidity1122.lean`, `ControlledDescentLogRatioSqueezeAndRigidity1122.lean`):**
  - `controlled_descent_telescoping_additive_defect_bound` and `coprime_additive_mul_of_isLittleO_descentCount_of_hasBoundedDownwardJumps`: establish the $K$-window telescoping bound $K|f(ab) - f(a) - f(b)| \le f(w_-(a, b, K + 1)) - f(w_-(a, b, 1)) + 2D \cdot \mathrm{descentCount}(f, X)$, which requires a downward-jump bound on the finite prefix $[1, X]$ together with the two endpoint range conditions $w_-(a, b, K + 1) \le X + 1$ and $a \cdot w_+(a, b, K) \le X + 1$, and deduce complete additivity $f(ab) = f(a) + f(b)$ under $|A \cap [1, X]| = o(X)$ and bounded downward jumps $f(n) - f(n + 1) \le D$.
  - `controlled_descent_log_ratio_diff_le_descentCount`, `sublogarithmic_descentCount_eq_scaled_log_of_hasBoundedDownwardJumps`, `trajectory_sublinear_descent_eq_scaled_log_of_hasBoundedDownwardJumps`, and `exists_zero_descent_shifted_div_trajectory_of_mul_descentCount_lt`: prove the controlled-descent logarithmic ratio squeeze (which uses a prefix jump bound, power additivity, and a finite range condition, with no $o(X)$ premise), logarithmic rigidity under $|A \cap [1, X]| = o(\log X)$ together with bounded downward jumps, logarithmic rigidity under $|A \cap [1, X]| = o(X)$ together with bounded downward jumps and trajectory descent $o(k)$ for every base $b \ge 2$, and pigeonhole existence of zero-descent shifted division trajectories.
  - `isScaledLogOnPos_iff_exists_boundedDyadicShellOscillation_of_isLittleO_descentCount_of_hasBoundedDownwardJumps` and `erdos1122_conjecture_of_boundedDownwardJumps_and_dyadicShellOscillation`: establish the exact equivalence $\mathrm{IsScaledLogOnPos}(f) \leftrightarrow \exists C,\, \mathrm{HasBoundedDyadicShellOscillation}(f, C)$ under $|A \cap [1, X]| = o(X)$ and bounded downward jumps.
- **Binary-Carry Doubling Decompositions, Iterated Binary-Halving Bounds, and Sub-Shell Rigidity Reductions (`Blueprint1122.lean`):**
  - `completely_additive_dyadic_step_bounds_of_hasBoundedDownwardJumps`, `completely_additive_dyadic_shell_complement_eq`, `completely_additive_dyadic_shell_window_oscillation_bound`, `completely_additive_iterated_binary_halving_defect_le`, `completely_additive_iterated_simultaneous_binary_halving_diff_le`, and `completely_additive_pow_two_shell_oscillation_of_hasBoundedDyadicShellOscillation`: formalize binary-carry odd/even step bounds, the dyadic-shell complementary identity $(f(q) - f(u)) + (f(2u) - f(q)) = f(2)$, window-localized dyadic-shell oscillation bounds, iterated binary-halving bit-length defect bounds, and multi-shell oscillation bounds across $[2^s u, 2^{s+1} u]$.
  - `isScaledLogOnPos_of_isLittleO_descentCount_of_hasBoundedDownwardJumps_of_subshell_downward_drift`, `isScaledLogOnPos_of_isLittleO_descentCount_of_hasBoundedDownwardJumps_of_shell_descent_card_le`, and `isScaledLogOnPos_of_isLittleO_descentCount_of_hasBoundedDownwardJumps_of_bitLength_zero_shell_bound`: each separately assumes, on top of $|A \cap [1, X]| = o(X)$ and bounded downward jumps, one extra uniform bound on the descent of $f$ within a dyadic shell — a sub-shell downward drift bound, a bounded shell descent count, or a half-open shell oscillation bound — and derives $f(m) = \frac{f(2)}{\log 2} \log m$ for all $m \ge 1$.
  - `erdos_1122_of_boundedDownwardJumps_and_subshell_downward_drift`: one of two Core theorems that conclude the package's descent-count formulation `Erdos1122Conjecture`. It takes as global hypotheses that every coprime-additive $f$ with $|A \cap [1, X]| = o(X)$ has bounded downward jumps and admits a uniform sub-shell downward drift bound, and it combines them into a conditional proof of the main conjecture. The other conditional reduction, `erdos1122_conjecture_of_boundedDownwardJumps_and_dyadicShellOscillation`, replaces the drift hypothesis with a uniform bounded dyadic-shell oscillation hypothesis. None of these uniformity hypotheses is established here, so the main conjecture remains open.
